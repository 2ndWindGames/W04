# 소복 · SOBOK

## 쌓아서 돌파하기

이동하는 블록으로 탑을 만들고, 탑 전체를 발사해 벽의 구멍을 통과시키는 액션 프로토타입입니다. 다음 벽의 계단형 구멍을 보며 탑의 모양을 만들고, 살아남은 탑으로 연속 돌파와 최고 점수에 도전합니다.

- 클릭 / 스페이스 / 화면 터치로 이동 중인 블록을 놓습니다.
- 아래 블록과 가로로 0.12 이상 겹치면 블록 전체가 놓입니다. 배치할 때 튀어나온 부분을 자르지 않으므로, 좌우로 어긋난 모양도 만들 수 있습니다. 지지할 만큼 겹치지 않으면 게임이 끝납니다.
- 블록 5개를 쌓으면 발사 준비 상태가 됩니다. 한 번 더 클릭 / 스페이스 / 터치하면 탑 전체가 벽으로 날아갑니다.
- 벽에 닿을 때 각 층에서 구멍 바깥으로 튀어나온 부분이 잘려 날아갑니다. 잘린 뒤에도 아래부터 연속해서 지지되는 블록만 살아남습니다.
- 살아남은 탑은 다음 라운드에 유지됩니다. 그 위에 블록 5개를 더 쌓고 다음 벽에 도전합니다.
- 잘린 조각이 있다면 충돌 뒤 짧은 회수 기회가 주어집니다. 금색 타이밍에 한 번 더 누르면 다음 이동 블록의 가로 폭을 최대 0.8 늘릴 재료를 회수합니다. 이미 놓인 탑의 폭을 즉시 복구하는 기능은 아닙니다.
- 회수는 한 번만 시도할 수 있습니다. 너무 이르거나 늦게 누르거나 그냥 보내도 추가 페널티 없이 이어집니다.
- 탑이 전부 사라지면 게임이 끝납니다. 종료 화면에서 기록을 확인하고 탑 이미지를 공유하거나 다시 시작할 수 있습니다.
- M / Sound 버튼으로 사운드를 켜거나 끕니다.

정원 미션, 배치 직후 잘림·회수, 빛을 소비하는 폭 회복은 현재 돌파 플레이에 사용하지 않습니다.

## 실행과 미리보기

Unity 6000.3.23f1에서 `Assets/Scenes/SampleScene.unity`를 열고 Play를 누릅니다. 씬의 `StackGame`이 탑, 돌파 벽과 HUD를 생성합니다. 별도의 외부 에셋은 필요 없습니다.

현재 Windows 미리보기 경로는 `Builds/BreachPreview/SobokBreach.exe`입니다. 실행 검증 결과와 실제 플레이 화면은 `resources/breach-preview/`에 저장합니다. 개발 빌드에서 `-sobok-breach-check` 인수와 `SOBOK_BREACH_CAPTURE` 출력 경로를 지정하면 배치, 발사, 벽 충돌, 잘림, 지지 연결, 조각 회수, 실패와 재시작을 검증합니다. 검증은 제품명이 `SOBOK Breach Preview`인 별도 미리보기에서만 실행해 본 게임의 기록과 분리합니다.

`Builds/GardenPreview`, `Builds/RecoveryPreview`와 해당 `resources` 하위 폴더는 이전 프로토타입의 빌드·이미지 기록이며 현재 돌파 플레이를 반영하지 않습니다.

## 화면과 사운드

무광 파스텔 블록과 낮·노을·밤·새벽으로 이어지는 배경을 유지합니다. 진한 청록색 벽과 밝은 구멍 테두리로 다음에 통과해야 할 모양을 보여줍니다.

`SobokSky`와 `Resources/SobokSky.shader`가 그라데이션 하늘, 겹친 언덕, 해·초승달·별·작은 구름을 그립니다. 배경은 카메라를 따라가며 세로·가로 비율에 맞춰집니다. `SobokAudio`의 직접 합성한 피아노풍 배경음과 배치·충돌·회수 효과음을 사용합니다.

SOBOK 앱 이름과 `Assets/Art/Branding/Sobok-Icon.png`를 기본 및 Android 아이콘에 연결했습니다. Adaptive 슬롯은 동일한 정사각 이미지를 두 레이어에 사용하며 별도 투명 전경은 없습니다. 아이콘은 내장 image_gen으로 제작했으며 전체 프롬프트는 같은 폴더의 `SobokGenerationNotes.md`에 있습니다.

## 수동 확인

1. 클릭, 스페이스, 터치가 각각 블록 하나만 놓는지 확인합니다. Sound 버튼 입력으로 블록이 놓이면 안 됩니다.
2. 블록을 조금 어긋나게 놓아도 전체 모양이 유지되는지, 가로 겹침이 0.12 미만이면 종료되는지 확인합니다.
3. 다섯 번째 배치 직후 자동 발사되지 않고, 다음 입력으로 탑 전체가 벽을 향해 날아가는지 확인합니다.
4. 벽의 구멍 안에 맞춘 층은 남고, 바깥 부분만 충돌 순간 잘려 나가는지 확인합니다. 아래층과 연결되지 않은 위쪽 블록이 공중에 남으면 안 됩니다.
5. 일부 탑을 남긴 채 돌파한 다음, 남은 탑 위에 새로운 블록을 다섯 개 쌓아 다음 벽으로 이어지는지 확인합니다.
6. 금색 구간에서 한 번 눌렀을 때 다음 이동 블록만 최대 0.8 넓어지는지 확인합니다. 너무 이른 입력, 늦은 입력, 무입력, 같은 프레임의 중복 입력도 확인합니다.
7. 전부 잘리는 경우의 종료, 이미지 공유, 재시작을 확인합니다. 재시작 시 이전 탑·벽·회수 보너스가 남으면 안 됩니다.
8. 세로 Game 뷰에서 탑, 벽 구멍, 발사·회수 안내와 사운드·공유 버튼이 화면 안에 보이는지 확인합니다.

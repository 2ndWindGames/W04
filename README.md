# 소복 · SOBOK

크림색 배경과 무광 파스텔 블록, 느린 움직임의 힐링 게임 더미입니다.
32초 피아노풍 배경음과 타격음·종소리는 SobokAudio에서 직접 합성합니다.
M 또는 오른쪽 위 Sound 버튼으로 소리를 끌 수 있습니다.
화면은 층수를 중심으로 표시하고, 점수와 로컬 기록은 종료 후 표시합니다.
아래의 기존 에너지는 작은 빛, OVERCHARGE는 A little room으로 표시합니다.
정확 판정 문구는 Just right., 종료 문구는 A little pause.입니다.
잘린 조각과 보상 띠는 배경색으로 흐려진 후 사라집니다.

SOBOK 앱 이름과 `Assets/Art/Branding/Sobok-Icon.png`를 기본 및 Android 아이콘에 연결했습니다.
Adaptive 슬롯은 동일한 정사각 이미지를 두 레이어에 사용하며 별도 투명 전경은 없습니다.
아이콘은 내장 image_gen으로 제작했으며 전체 프롬프트는 같은 폴더의 SobokGenerationNotes.md에 있습니다.
소리 버튼을 누를 때 블록이 놓이지 않는지, 루프가 자연스러운지도 Play에서 확인하세요.

Unity 6000.3.23f1에서 `Assets/Scenes/SampleScene.unity`를 열고 Play를 누릅니다.
씬에 연결된 `StackGame`이 블록과 HUD를 생성합니다. 외부 에셋은 필요 없습니다.

- 클릭 / 스페이스 / 화면 터치: 이동 중인 패널 쌓기
- 어긋난 부분은 떨어지며, 겹치는 부분이 없으면 게임 오버
- 정확히 쌓기: 에너지 +1 (최대 6), 해당 층에 밝은 띠 표시
- 에너지 0~1 / 2~3 / 4~5 / 6: 점수 배율 x1 / x2 / x3 / x4
- 한 층당 10 × 배율 점수
- E 또는 하단 OVERCHARGE 영역 터치: 에너지 3을 사용해 현재 발판과 이동 패널의 X/Z 폭을 각각 0.6 회복 (최대 3)
- 게임 오버 후 클릭 / 스페이스 / 터치: 재시작
- 최고 점수와 상위 5개 기록은 PlayerPrefs에 기기별로 저장됩니다. 온라인 랭킹은 없습니다.

## 수동 확인

1. Play 후 클릭, 스페이스, 터치로 각각 한 층씩 놓이는지 확인합니다.
2. 중심에서 놓아 PERFECT와 에너지가 증가하는지 확인합니다.
3. 가장자리에서 놓아 잘린 조각이 떨어지고 다음 블록 폭이 줄어드는지 확인합니다.
4. 에너지 3 이상에서 E 또는 OVERCHARGE를 눌러 폭이 회복되고 에너지가 3 감소하는지 확인합니다. 이 입력으로 블록이 놓이면 안 됩니다.
5. 완전히 빗나가게 놓아 게임 오버, 상위 기록 저장, 재시작을 확인합니다.
6. 세로 Game 뷰에서도 점수와 오버차지 영역이 보이는지 확인합니다.
